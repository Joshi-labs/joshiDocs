**[docs.vpjoshi.in](https://docs.vpjoshi.in)** is a lightweight, CI/CD-integrated documentation server built to house the technical blueprints, architecture diagrams, and post-mortems of every Cloud, DevOps, and SDE project in my portfolio.

---

## 🛠️ Tech Stack
- **Frontend:** React 19 + Vite (Ultra-fast HMR)
- **Styling:** Tailwind CSS 4 (Modern utility-first CSS)
- **Animations:** Framer Motion (Smooth page & component transitions)
- **Icons:** Lucide React
- **Routing:** React Router 7
- **Deployment:** GitHub Actions + GitHub Pages (Automated CI/CD)

---

## ✨ Key Features
- **JSON-Driven Content:** Zero-database architecture. Every document is a portable JSON file.
- **Dynamic Rendering:** Custom block-based renderer supporting:
    - 💻 Syntax-highlighted Code Blocks
    - 🖼️ Zoomable Image Modals
    - 📄 Embedded PDF Viewers
    - ⚠️ Interactive Alerts (Info, Warning, Tip)
    - 🎥 Video Embeds
- **CI/CD Integrated:** Automated build and deployment pipelines ensure the docs are always in sync with the latest commits.
- **Optimized for Mobile:** Fully responsive design with sidebar-driven navigation for deep technical reads.

## ⚡ Quick Start
### Prerequisites
- Node.js (v18+)
- npm / yarn

### Local Development
```bash
# Clone the repository
git clone https://github.com/Joshi-labs/joshiDocs.git

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
```
